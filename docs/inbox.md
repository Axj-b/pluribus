# Inbox

> Capture first, organize later. Add anything here that is not yet a note, decision or question.

## How to use

- Add a bullet under **Unsorted** with enough context to understand it later.
- During triage, move each item into one of:
  - a question in [`questions/README.md`](questions/README.md);
  - a decision record in [`decisions/`](decisions/README.md);
  - a note in [`notes/`](notes/README.md);
  - a concrete task in [`maps/implementation.md`](maps/implementation.md);
  - the [implementation log](log/README.md).
- Delete an item only when it is captured somewhere durable, answered, or deliberately dropped.
- Keep this file short; it is a buffer, not an archive.

## Unsorted

- None at the last triage.

## Triage checklist

- [ ] Is this a fact, a question, a decision, or a task?
- [ ] Does an existing note or spec already cover it?
- [ ] Which map should eventually link to it?
- [ ] What is the smallest durable artifact that captures it?
- [ ] Does an open question need a status or next action?
